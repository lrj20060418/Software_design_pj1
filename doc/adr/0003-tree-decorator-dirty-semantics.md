# ADR-0003：树标签 dirty 语义与拼接顺序

- **状态**：已采纳（Exp-T0）
- **日期**：2026-11-26

## 决策

### 1. dirty 判定：`内容 ≠ 上次保存/读入/init 基线`

`modified-star` 在 `onAfterSave` / `onAfterReset` 时对每节点拍 SVG 指纹基线。  
`decorate` 时比较当前指纹：不同则标 ` *`。  
→ **undo 回到与基线一致的内容后 `*` 消失**（不是「发生过编辑就永久标星」）。

### 2. 祖先传播：**不传播**

仅被改动的节点行标 `*`。画布根行 `svg (WxH)` 在「文档存在任一 dirty（含新建/删除）」时标 ` *`，中间容器不因子孙变脏而自动标星。

### 3. 新建节点：**立即 dirty**

基线中不存在的 id 视为 dirty，创建后未保存即标 `*`。

### 4. 多标签拼接顺序

按 **装饰器注册顺序** 依次 `decorate`。默认装配先 `box-type-label` 再 `modified-star`，故同行形如：

`├── g#n1 (box) *`

两插件互不读取对方状态。

### 5. `(box)` 归属

由 `tree-box-label` 插件追加；`Box.treeLabel()` 只输出 `g#id`，渲染器/内核不为 box 特判标注。
